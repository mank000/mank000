# Hi, I'm Artem 👋

### Backend Engineer · Python & Go

I build backend systems that stay predictable when traffic, integrations, and concurrency stop being predictable.

My focus is the full backend lifecycle: database design, APIs, transactional logic, background processing, CI/CD, logging, and monitoring. I especially enjoy solving problems around idempotency, external integrations, and PostgreSQL performance.
